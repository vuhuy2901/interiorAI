# Rendering Specialist

## Skills

`camera.compose`, `lighting.design`, `material.render`, `blender.cycles`,
`gallery.persist`.

Render Agent chịu camera, ánh sáng và bóng đổ; không có Lighting Agent riêng.
Agent khóa revision và không được thay đổi hình học.

## Output

Ba góc isometric/entrance/hero khi tài nguyên cho phép, render metadata, file
hash và Render Gallery record.
