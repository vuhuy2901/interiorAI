## 1. Bối cảnh

The child-bedroom presentation scene was generated by a manual script with a fixed
project ID, room outline, openings, furniture, colours and dimensions. It can be
mistaken for a specialist-agent result. Native workflow dispatch also resolves a
Paperclip project by name/description matching rather than the persisted Studio-to-
Paperclip link, and successor tasks currently receive paths without verified
handoff provenance.

## 2. Mục tiêu

No runtime path may manufacture a scene from fixed child-bedroom data. A native
task may be created only for the exact persisted Paperclip Project linked to the
canonical Studio scene, and a successor receives verified predecessor handoff
metadata (manifest path, artifact ID and SHA-256). Missing linkage or handoff
must block that node without falling back to Chief or a demo project.

## 3. Phạm vi

### In scope

- Remove the manual fixed child-bedroom presentation script without touching
  existing projects or revisions it previously created.
- Replace name/description Paperclip project lookup with the explicit
  `atelier_scene_links` / `native_project_links` mapping and company check.
- Require validated predecessor handoffs before native successor dispatch; attach
  their verified metadata to the native task description.
- Remove the demo-project fallback during run reconciliation.
- Reject a catalogue replacement that lacks an explicit Pascal asset ID instead
  of silently assigning `sofa`.
- Add focused automated tests.

### Out of scope

- No project/revision/task/run deletion, database migration, UI redesign,
  workflow/scheduler rewrite, provider/key change, backend restart, or geometry
  and rendering redesign.
- No automatic provisioning of a Paperclip Project link.

## 4. Dependency và tài nguyên cần bảo vệ

- Dependency: SQLite links, Paperclip official task API, workflow runtime.
- Dữ liệu dùng chung: all existing Studio projects, revisions, workflow runs,
  native tasks and Paperclip projects are read-only for this implementation.
- Service/port/database không được ảnh hưởng: no backend restart and no live
  Paperclip mutation during verification.

## 5. Thiết kế và kế hoạch triển khai

1. Remove the fixed-data script.
2. Query the persisted scene-to-native-project relation for task dispatch and
   reject absent or cross-company mappings.
3. Validate every predecessor manifest before dispatch and pass its provenance.
4. Block an incomplete run missing its canonical project ID rather than substituting
   a demo project.
5. Add tests for each refusal and the valid linked handoff path.
