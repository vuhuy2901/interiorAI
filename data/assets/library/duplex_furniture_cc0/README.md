# Duplex furniture GLB library

Downloaded for the Duplex project on 2026-11-19.

Source pack: https://3dassets.dev/packs/bedroom-and-living-room-furniture

License: CC0 1.0 Universal. The pack is free to use, modify and redistribute, including in commercial work, without attribution.

Format: self-contained `.glb` files with embedded textures.

Units: metres, +Y up.

The pack contains 55 individual choices covering:

- beds: double, single, bunk, daybed and headboards
- seating: two-seat sofa, three-seat sofa, corner sofa, loveseat, armchair, chaise and pouffe
- tables: coffee, side, console, writing and dining tables
- chairs: dining, task and rocking chairs
- storage: wardrobes, chest of drawers, tallboy, bookcase and blanket box
- lighting: floor lamps, table lamp, desk lamp, pendant lamps and wall sconce
- soft furnishing and decor: rugs, curtains, blinds, cushions and throws
- room modules: floor, walls, window wall, door wall and ceiling

The original project model is kept separately at:

`../duplex_source/the_interior_14_is_spacious.glb`

This library is for interior layout, visualization and asset selection. It does not change the canonical architectural dimensions of the Duplex model and does not constitute a construction specification.
